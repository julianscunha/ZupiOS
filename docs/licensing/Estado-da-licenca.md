# Estado da licença do ZupiOS

A licença definitiva do ZupiOS **ainda não foi escolhida**.

O projeto está avaliando um modelo *source-available* com restrições comerciais, mantendo como objetivo o uso gratuito do sistema, a possibilidade de modificações e redistribuição não comercial e a comercialização independente de aplicações.

A formulação final precisa resolver a diferença entre uso comercial gratuito do sistema por uma empresa e a venda ou exploração comercial de uma versão derivada.

> [!warning] Não tratar os objetivos como licença
> Este texto é informativo e não substitui um arquivo `LICENSE`. A publicação pública do código não significa, por si só, que o projeto conceda todos os direitos típicos de uma licença open source.

Consulte [[../../planning/decisions/0002-politica-de-licenciamento|a decisão de planejamento sobre licenciamento]].
