# Visão geral do SDK

## Objetivo

O ZupiOS terá um SDK próprio para que desenvolvedores construam aplicações usando um contrato público definido pelo projeto.

## Ainda não definido

- Linguagem e ferramentas oficiais.
- APIs da primeira versão.
- Formato de pacote de aplicações.
- Runtime e modelo de isolamento.
- Ciclo de vida, permissões e acesso a recursos do dispositivo.
- Política de versionamento e estabilidade das APIs.

Os casos de uso e requisitos de compatibilidade propostos para o produto estão em [[planning/compatibility-requirements|Requisitos de compatibilidade]]. A proposta v0.2 ainda não foi aprovada e não equivale a um contrato de API definido.

## Diretriz

Não documentar uma API como disponível até que sua especificação, implementação e testes correspondentes estejam publicados. Propostas de API pertencem ao planejamento até serem aprovadas.
