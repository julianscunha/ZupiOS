# Visão geral do ZupiOS

## Propósito

O ZupiOS pretende oferecer uma plataforma de software para televisores com um SDK próprio, buscando reduzir a fragmentação de APIs e melhorar a compatibilidade de aplicações entre dispositivos.

## Princípios de produto já definidos

- O sistema deve ser utilizável sem cobrança por instalação ou dispositivo.
- O SDK deve ser próprio e não depender de um único ecossistema de aplicações de terceiros como contrato público.
- O projeto pretende receber contribuições da comunidade, com revisão e aprovação do mantenedor.
- Doações são opcionais.
- Os serviços comerciais planejados não devem tornar o uso básico do sistema pago.

## Limites atuais

- A lista de dispositivos compatíveis não está definida.
- A arquitetura técnica não foi aprovada.
- A compatibilidade real só será declarada após testes documentados.
- A licença definitiva ainda não foi escolhida.
- Os casos de uso e requisitos de compatibilidade estão descritos em uma proposta separada, ainda pendente de aprovação.
