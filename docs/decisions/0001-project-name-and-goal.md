# Decisão 0001 — Nome e objetivo do projeto

- **Estado:** provisório
- **Data:** 2026-10-19

## Decisão

Usar **Zupi** como nome de trabalho do projeto.

## Objetivo

Desenvolver uma plataforma para televisores com SDK próprio para aplicações, buscando padronizar as APIs oferecidas aos desenvolvedores e reduzir a fragmentação entre dispositivos.

## Observações

O nome ainda precisa de validação de marca e domínio. O escopo técnico e os dispositivos-alvo serão definidos separadamente, com base em testes verificáveis.
