# Decisão 0002 — Objetivos de licenciamento

- **Estado:** requisitos definidos; texto jurídico e licença ainda pendentes
- **Data:** 2026-10-19

## Objetivos acordados

1. O código deverá ser público desde o início.
2. A comunidade poderá estudar e modificar o código para uso próprio.
3. A redistribuição gratuita de versões modificadas será permitida para fins não comerciais.
4. O uso do sistema por pessoas e empresas será gratuito, sem cobrança por instalação ou dispositivo.
5. Aplicações independentes criadas com o SDK poderão ser comercializadas por seus desenvolvedores.
6. Contribuições de código poderão ser propostas por pull requests e serão incorporadas somente após aprovação do mantenedor.
7. O projeto poderá receber doações opcionais e oferecer serviços comerciais próprios, como atualização automática via SaaS e divulgação de aplicações no marketplace.
8. A comercialização de versões derivadas do próprio sistema deverá depender de autorização, conforme os limites a serem definidos na licença.

## Questões que ainda exigem definição

- Como distinguir juridicamente a venda/distribuição comercial de uma versão derivada do uso comercial gratuito do sistema por uma empresa.
- Se e como a licença tratará monetização indireta de versões derivadas.
- Direitos concedidos aos colaboradores e necessidade de CLA ou outro instrumento.
- Tratamento de módulos, dependências e componentes de terceiros com licenças próprias.
- Direitos sobre marcas, nomes, logotipos e serviços oficiais.

## Nota importante

Este documento registra intenções de produto; não é uma licença nem aconselhamento jurídico. Não foi incluído arquivo `LICENSE` porque o texto definitivo ainda não foi escolhido. A classificação pretendida é *source-available* com restrições comerciais, não uma licença open source convencional.
