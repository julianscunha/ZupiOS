# Serviços opcionais

Este documento registra intenções de produto, ainda não implementadas.

## Atualizações automáticas

O projeto pretende oferecer um serviço SaaS para consultar e distribuir atualizações. Protocolo, assinatura, segurança, disponibilidade offline e política de suporte ainda precisam ser definidos.

## Marketplace

O projeto pretende permitir a publicação e instalação local de aplicações. Uma opção comercial planejada é cobrar pela promoção ou divulgação de aplicações no marketplace. Os desenvolvedores poderão comercializar seus próprios aplicativos independentemente do marketplace oficial.

## Doações

O uso básico do ZupiOS não deve depender de pagamento. A contribuição financeira para o desenvolvimento será voluntária.

## Telemetria e identificação

A intenção de medir ativações, tipos de dispositivos e dados técnicos para melhorar a compatibilidade ainda exige uma decisão de privacidade e desenho técnico. Nenhuma coleta deve ser descrita como anônima apenas por usar um token ou identificador persistente.

Antes de implementar, definir minimização de dados, transparência, consentimento quando aplicável, retenção, controles do usuário e adequação legal.

## Estado

Nenhum destes serviços está declarado como implementado ou disponível.
