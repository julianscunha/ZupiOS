# Decisão 0001 — Nome e objetivo do projeto

- **Estado:** aceita
- **Data:** 2026-10-19

## Decisão

O nome oficial do sistema e do projeto será **ZupiOS**. O repositório principal é `julianscunha/ZupiOS`.

## Objetivo aprovado até aqui

Construir uma plataforma de software para televisores com SDK próprio para aplicações, priorizando compatibilidade entre dispositivos e APIs consistentes para desenvolvedores.

## Ainda não definido

- Hardware inicial suportado.
- Sistema-base e runtime.
- Escopo da primeira versão funcional.
- Estratégia final de marca, domínios e registro da marca.
