## Regras de manutenção

- Registrar uma decisão em ADR somente após confirmação explícita.
- Separar fatos confirmados, hipóteses e questões pendentes.
- Não tratar intenção de produto como arquitetura ou funcionalidade implementada.
- Ao substituir uma decisão, registrar o motivo e atualizar referências afetadas.
- Cada assunto deve ter uma fonte de verdade; outros documentos devem resumir apenas o necessário e apontar para ela.
