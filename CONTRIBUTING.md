# Contribuindo com o ZupiOS

Contribuições são bem-vindas em forma de relatórios de bugs, resultados de testes de dispositivos, documentação, propostas e alterações de código.

## Fluxo de contribuição

1. Abra uma issue antes de mudanças maiores para discutir o problema ou a proposta.
2. Para alterações de código, envie um pull request pequeno, com contexto, motivação e testes quando aplicável.
3. Aguarde a revisão e aprovação explícita do mantenedor. Enviar um pull request não garante sua incorporação.
4. Ao relatar testes de dispositivo, informe modelo exato, firmware, versão testada, passos reproduzíveis, resultado e limitações observadas.

## Direitos sobre contribuições

A política jurídica para contribuições externas ainda está em definição. Até que os termos sejam publicados, não envie código de terceiros sem direitos suficientes, material confidencial nem alterações cuja licença seja incompatível ou desconhecida.

O projeto poderá solicitar um acordo de contribuição antes de incorporar código externo. Os termos serão definidos antes de começar a aceitar contribuições sob uma política de licença definitiva.

## Licenciamento atual

O código está publicamente visível, mas a licença definitiva ainda não foi escolhida. Não presuma que a visibilidade pública conceda permissão geral de uso, modificação ou redistribuição. Consulte [o estado da licença](docs/licensing/Estado-da-licenca.md).
