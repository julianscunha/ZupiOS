# Contribuindo com o Zupi

Contribuições são bem-vindas, incluindo relatórios de bugs, resultados de testes em dispositivos, documentação, sugestões e alterações de código.

## Fluxo de contribuição

1. Abra uma issue para descrever o problema ou a proposta antes de mudanças maiores.
2. Para código, envie um pull request pequeno, com contexto e testes quando aplicável.
3. Aguarde a revisão e aprovação explícita do mantenedor; enviar um pull request não garante sua incorporação.

## Termos das contribuições

Os termos jurídicos para contribuições de código ainda serão definidos. Até que sejam publicados, não envie código de terceiros sem direitos suficientes nem informações confidenciais. O processo de contribuição será atualizado antes de aceitar contribuições sob uma licença definitiva.
